# Crossly

**Crossly** is an offline crossword puzzle game designed to provide a simple and enjoyable crossword experience.
Packed with amazing features, work 100% offline, zero ads, completely free

## Download

Get the latest version of Crossly from the [GitHub Releases](https://github.com/iamaffanyousuf/crossly-releases/releases) page.

## Installation

1. Download the latest `.apk` file from Releases.
2. Open the downloaded APK on your Android device.
3. Allow installation from unknown sources if prompted.
4. Complete installation and enjoy Crossly!

## OR

1. Go to [Crossly Game here](https://crosslygame.vercel.app/)
2. Now it will work on browser for free and offline, no internet will be needed unless you clear the cache
3. You can Install Offline PWA to your devices Phone/Tablets/PC using Install Offline Button directly or use browser's install option
4. And done, now you can enjoy Crossly completely offline

## Features

Crossly is packed with amazing feature and completely free
- Thousand of Puzzles
- Dozens of Categories
- Works 100% offline even in browser
- Next Level of Progress Tracking and offline Sync feature
- Portable Backup to survive reinstalls and even device switches
- Save Progress file on your device then import it to restore the progress
- Or you can use Code feature to restore the progress which is very straight forward and easy to use
  Copy the code and paste it on other device to restore/sync your progress
- Multiple themes for eye comfort and for easy to read
